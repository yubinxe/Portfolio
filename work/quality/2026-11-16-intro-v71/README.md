# Intro V7.1 — 시간 기반 재생 검증 기록 (2026-11-16)

## 근본 원인(변경 전)
장면 투명도 · 변형이 스크롤 진행도(`cine.js` → `--cp`, 520vh 고정 구간)에 직접 묶여 있었다. 휠 delta 가 크면 진행도가 한 번에 0 → 1 로 넘어가 중간 장면을 통과한다.
- 변경 전 측정(1440×900, 큰 휠 40회): 6개 장면 모두 노출 0.3초 미만, 문서 33,709px 지점까지 튕겨 나감.

## 새 구조
- `position:fixed` 막 + `requestAnimationFrame` 재생기 하나가 `--t`(초)를 쓴다. 스크롤 길이 없음.
- 입력(휠 · 트랙패드 · 스와이프 · 방향키 · Space)은 delta 크기와 무관하게 ‘가속 의사’로만 — 장면 사이 전환만 1.6배. 정지 구간(IX_HOLD)과 이름 장면은 가속 없음.
- 재생 중에만 `html.ix-lock`(배경 스크롤 잠금) · 인트로 밖 `inert`. 끝 · 바로 본문 · Esc · 인트로 끄기 · pagehide · error · 안전 시간(14.4초) · head 스크립트 6초 안전장치에서 해제.
